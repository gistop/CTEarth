# AI 助手模块

## 范围

当前实现浏览器直接连接 DeepSeek，保留原有聊天、模型选择、地图感知和十四个 GIS 工具。后端代理仅保留类型、适配器和禁用的 UI 入口；不会请求 `/api/chat`，也不会自动降级到其他服务。`VITE_AI_CHAT_API` 暂不参与运行。

本次是架构重构，不是完整 Agent 平台建设。没有新增模型依赖或把 GIS 运算搬到服务端。

## 目录与职责

```text
src/features/ai/
├─ components/   助手面板、消息、地图感知卡片、连接设置
├─ stores/       会话生命周期、设置与错误状态
├─ adapters/     DeepSeek 协议、聊天 UI 传输、GIS 状态桥接、代理占位
├─ services/     模型无关的任务编排、GIS 上下文、凭据存储
├─ tools/        工具定义、参数校验、执行器、GIS 调用契约
├─ testing/      测试数据与模拟业务接口，仅供测试引用
├─ types.ts      模型无关的消息、工具和模型接口
└─ index.ts      模块公开入口
```

应用通过 `features/ai` 懒加载助手。旧路径兼容入口已移除，所有调用统一使用模块公开入口。

```text
人工界面 ───────────────────────────────────┐
                                           ↓
                                      现有 GIS 操作
                                           ↑
助手 UI → 会话服务 → 编排服务 → 受控工具执行器 → AiGisPort
                       ↕
                   AiModelAdapter
                       ↕
                  浏览器模型 API
```

### 模型边界

- `AiModelAdapter` 接收统一的 `AiMessage`、`AiToolDefinition` 和取消信号，返回统一的助手消息。
- DeepSeek 的请求地址、认证方式、`tool_calls`、`reasoning_content` 和响应校验只放在 `deepSeekAdapter.ts` 中。
- 推理协议附加信息通过不透明的 `providerMetadata` 往返；编排服务不解释它，也不把它当普通回复展示。
- `browserChatTransport.ts` 只处理 assistant-ui/AI SDK 的消息和流生命周期，不了解 GIS 或 DeepSeek 协议。
- 当前网络请求仍采用完整响应（`stream: false`），完成后转换成 UI 消息流；不是逐 token 的网络流式输出。

### GIS 边界

- `AiGisPort` 是 AI 使用 GIS 能力的窄接口，不要求图层管理或分析模块依赖 AI 类型。
- 工具执行复用 `GisProvider` 的普通操作；选择接口显式传入目标图层 ID。
- 缓冲区、相交、联合、擦除、IDW、栅格计算和地形操作使用 `GisOperationResult<TOutput>` 返回值。矢量分析返回登记后的 `UploadedLayer`，AI 使用其真实 ID 作为 `resultLayer.id`，等待对应结果提交到图层集合后才继续；不再使用固定的 `vectorOverlay` 结果 ID。
- 栅格计算（`raster_calculator`）在浏览器内以纯 JS 逐像元求值地图代数表达式：栅格以双引号名称引用（`list_layers` 返回的栅格名），支持 `+ - * / %`、比较、`&& || !`、括号和 `abs sqrt ln log log10 exp pow min max floor ceil round con isnull` 函数；表达式解析与校验收敛在工具箱的 `rasterCalculatorEngine` 纯服务中，传统表单、AI 执行器和 store 共用同一实现。所有被引用栅格必须网格一致，nodata 或无效像元传播到输出。
- 重分类（`raster_reclassify`）同样以纯 JS 实现，收敛在 `reclassifyEngine` 纯服务：自然间断点（Fisher-Jenks，超过 2048 个值时等距抽样）、分位数（顺序统计量）、等间距和自定义间断点四种方法；每个类至少含一个有效值，否则自动收敛类数；输出为 1..N 的类别号并返回间断点与逐类像元数直方图，供模型向用户汇报。
- 重采样（`raster_resample`）以纯 JS 实现于 `resampleEngine` 纯服务（WASM `resample` 仅支持 nn/bilinear/cc，无众数，故未复用）：最邻近、双线性、三次卷积（Keys 核，a = -0.5）与众数（降采样取覆盖像元中心值的众数，平票取较小值；上采样回退最邻近）；按目标像元大小推算输出网格并保持原点，仅支持北向上栅格，输出维度超过 20000 时拦截；nodata 像元传播，插值仅对有效邻居加权归一。
- 工具箱和 AI 生成的同名结果也作为独立图层新增，输入与历史结果保留。AI 可以连续处理自己生成并激活的图层，但用户在请求期间切换到其他输入仍会被状态校验拦截。
- AI 根据操作返回的实际结果判断成功或失败，不再通过两次 `requestAnimationFrame` 猜测结果是否生成。
- React 桥接层在成功后等待对应结果提交到共享状态，再允许后续工具读取；等待通过提交通知完成，不靠动画帧轮询。关闭面板会清理等待，异常情况下等待最多 10 秒。
- 图层名称格式化提取到图层模块的纯服务；`gisStore.tsx` 继续兼容导出，避免 AI 上下文服务加载整个 GIS 运行时。

## 执行约束

1. 请求开始时读取当前 GIS 上下文，地图字段和属性作为不可信数据而非指令发送。
2. 仅暴露注册的十四个工具：图层检查、缓冲区、属性选择、空间选择、相交、联合、擦除、山体阴影、坡度、坡向、IDW、栅格计算、重分类、重采样。相交、联合和擦除要求显式传入两个不同的 Polygon/MultiPolygon 图层 ID；栅格计算要求表达式引用的栅格共享同一网格。
3. 执行前校验 JSON 对象、必填字段、类型、枚举、数值范围和未知参数；非法数值、布尔值和枚举不会被静默替换成默认值。省略的可选参数采用默认值，空输出名等文本参数仍遵循原有业务默认规则。
4. 检查活动输入变化、图层与字段是否存在、GIS 是否忙碌以及需要时的 WASM 就绪状态。请求期间切换活动输入会阻止相关操作，不会静默改用新图层。
5. 每个请求默认最多四轮工具调用、十二次工具调用；工具串行运行。同一回复的调用数量超预算时整批不执行，重复调用标识会终止本次流程。
6. 达到工具轮数预算后，可再请求一次不带工具的最终说明。失败结果回传模型，不能因旧结果仍显示在地图上就报告成功。
7. 每次模型请求前后、每次工具执行前后均检查取消信号。重置会话、关闭面板和更改连接设置会取消旧请求。普通地图状态刷新不会重建或取消正在运行的会话传输。

这些是浏览器端的执行约束，不是服务端权限控制或完整的提示词注入防护系统。

## 凭据与数据

- 默认仅在内存保存用户输入的 API Key。用户主动启用本机保存后才写入 `localStorage`，沿用旧键 `ctearth-ai-deepseek-key`。
- 本机保存不是加密保险箱，同源脚本可以读取它。设置中明确提示仅在可信设备保存，并告知会发送 GIS 摘要及部分属性。
- 禁用保存会尝试删除本机密钥。浏览器拒绝存储访问时显示错误，不阻断仅使用内存密钥的直连；删除失败时提示用户清除站点存储。
- 上下文不发送矢量完整几何、栅格像素、原始文件或密钥。选中要素预览最多五个，每个最多十二个属性；选择索引最多一百个，超出时明确标记截断。
- HTTP 错误不直接展示服务端原始响应体，避免意外回显敏感信息。
- 重置聊天保留当前连接设置，但清空聊天运行时；对话本身没有跨刷新持久化。

## 扩展方式

### 接入其他模型

1. 在 `adapters/` 实现 `AiModelAdapter`，提供供应商描述、模型列表和能力声明。
2. 在会话组合入口 `stores/useAiSession.ts` 接线，替换默认适配器及供应商描述。
3. 为新适配器增加协议转换、错误和取消测试。

不修改 GIS 算法、工具参数或人工界面。协议差异留在适配器内；如果新增的是视觉等真正的新能力，则按能力扩展统一契约，而不是假设所有模型完全等价。

### 接入新的 GIS 工具

1. 先确保普通 GIS 业务接口可以独立调用，人工入口继续复用该接口。
2. 按需扩展 `AiGisPort` 和桥接层。
3. 添加统一工具定义及对应处理函数，并覆盖参数错误、业务失败和成功结果测试。

不得把 GIS 算法复制到模型适配器里，也不得让模型返回的任意名称调用任意业务函数。

## 暂未实现的能力

- 分析计划预览、逐步用户确认、持久化执行审计、事务回滚及撤销/重跑 UI。
- 正在执行的底层 WASM 任务的强制中断。取消会阻止后续请求和工具，但已开始的运算仍可能完成并更新地图，不能视为撤销。
- 真正的逐 token 流式响应、多模态、自动模型路由和后台代理。
- 完整 CRS 语义推理。矢量坐标提示仍基于范围启发式，不能把它当成已验证坐标系；缓冲距离仍沿用现有业务工具的输入坐标单位。
- 完整的上下文总量预算和敏感字段白名单。大规模图层目录或敏感数据场景应先补齐相应策略。
